VISUAL PORTFOLIO — PUBLISHING GUIDE

CONTENTS
- index.html: the public portfolio page.
- portfolio.json: work titles, descriptions, and order.
- media/: images and videos used by the page.

PUBLISH WITH GITHUB PAGES
1. Unzip this file.
2. On GitHub, create a new repository (for example, portfolio).
3. Upload the contents of this folder to the repository root. index.html must be at the root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and the /(root) folder, then save.
7. When publishing is complete, open the URL shown in Settings > Pages.

UPDATES
Edit your collection in the original editor, click “Export site” again, and replace the previously published files on GitHub with the files from the new ZIP.

IMPORTANT
The public page is read-only. Your edits are saved in the browser where you work; to make them visible to visitors, export and publish the site again. The media files are included in this package.
