VISUAL ARCHIVE — EDITOR DE PORTFOLIO BILINGÜE

IDIOMAS
- La página abre en inglés por defecto.
- Usa los botones EN / ES de la parte superior para cambiar entre inglés y español.
- El idioma elegido se guarda en ese navegador.
- Al exportar el sitio público, se utiliza como idioma inicial el que esté seleccionado en ese momento.

CÓMO USAR EL EDITOR
1. Abre index.html en Chrome o Microsoft Edge.
2. Pulsa “Importar archivos” / “Import files” y selecciona imágenes o videos.
3. Haz clic en una pieza para verla ampliada y editar su título y descripción.
4. Los cambios se guardan automáticamente en el almacenamiento local de ese navegador.
5. Cuando termines, pulsa “Exportar sitio” / “Export site”. Se descargará un ZIP con la versión pública y sus archivos multimedia.

PUBLICAR EN GITHUB PAGES
1. Descomprime el ZIP que genera el botón de exportación.
2. Crea un repositorio en GitHub y sube el contenido del ZIP a la raíz (index.html debe quedar en la raíz).
3. Abre Settings > Pages.
4. En Build and deployment, selecciona Deploy from a branch.
5. Elige la rama main y la carpeta /(root); pulsa Save.
6. GitHub mostrará la URL pública cuando la publicación esté lista.

INSERTAR O ENLAZAR EN PAYHIP
La opción más fiable es añadir en tu tienda un botón o enlace a la URL pública de GitHub Pages. Si el editor de Payhip permite insertar HTML/iframe en la sección que estás editando, puedes probar con este código (reemplaza la URL):

<iframe src="https://TU-USUARIO.github.io/TU-REPOSITORIO/" title="Visual Archive Portfolio" width="100%" height="900" style="border:0;display:block;" loading="lazy"></iframe>

Comprueba la vista previa en Payhip: la disponibilidad de HTML/iframe puede depender del tipo de página o bloque que estés editando. Si no admite iframe, usa un enlace que abra el portfolio en una pestaña nueva.

IMPORTANTE SOBRE LOS DATOS
El editor guarda imágenes, videos y descripciones en IndexedDB, dentro del navegador y dispositivo donde se importaron. No existe sincronización automática entre dispositivos ni una base de datos compartida. La exportación genera una copia pública estática; para actualizarla, vuelve a exportar y reemplaza en GitHub los archivos publicados.
