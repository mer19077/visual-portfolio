VISUAL ARCHIVE — BILINGUAL PORTFOLIO EDITOR

LANGUAGES
- The page opens in English by default.
- Use the EN / ES controls at the top to switch between English and Spanish.
- Your language preference is saved in that browser.
- When you export the public site, the currently selected language becomes its initial language.

USING THE EDITOR
1. Open index.html in Chrome or Microsoft Edge.
2. Click “Import files” and choose images or videos from your device.
3. Select any item to view it larger and edit its title and description.
4. Changes are saved automatically in that browser's local storage.
5. When you are ready, click “Export site”. A ZIP containing the public portfolio and its media files will be downloaded.

PUBLISHING WITH GITHUB PAGES
1. Unzip the ZIP created by the Export site button.
2. Create a GitHub repository and upload the ZIP contents to its root. Make sure index.html is at the root level.
3. Open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose the main branch and /(root), then click Save.
6. GitHub will show your public URL when the site is published.

EMBEDDING OR LINKING FROM PAYHIP
The most reliable option is to add a button or link in your Payhip store that points to your GitHub Pages URL. If the Payhip editor allows custom HTML/iframes in the page or block you are editing, you can try the following code (replace the URL):

<iframe src="https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/" title="Visual Archive Portfolio" width="100%" height="900" style="border:0;display:block;" loading="lazy"></iframe>

Check the Payhip preview. HTML/iframe support may depend on the page type or block being edited. If iframes are not accepted, use a link that opens the portfolio in a new tab.

IMPORTANT — HOW STORAGE WORKS
The editor stores images, videos, titles, and descriptions in IndexedDB in the browser and on the device where you imported them. There is no automatic cross-device sync or shared database. Exporting creates a static public copy. To update it, export again and replace the published files on GitHub.
